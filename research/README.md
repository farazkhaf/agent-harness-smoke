# Research

This directory contains the study built with Agent Harness Smoke. The task packages, runtime, recorded results, and execution evidence remain shared with the reusable software rather than being duplicated here.

- [`STUDY_OBJECTIVE.md`](STUDY_OBJECTIVE.md) defines the research scope and questions.
- [`METHODS.md`](METHODS.md) describes the study design, evidence layers, route-coding procedure, and sampling interpretation.
- [`TASK_DESIGN_SOURCES.md`](TASK_DESIGN_SOURCES.md) indexes the task-authoring and validation records used as methodological sources.
- [`scenario-1/FINDINGS.md`](scenario-1/FINDINGS.md) contains the current Scenario 1 analysis.
