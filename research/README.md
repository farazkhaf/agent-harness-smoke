# Research layer

This directory contains the interpretive research layer built on top of Agent Harness Smoke. The reusable software, task definitions, runtime profiles, neutral result tables, and retained execution evidence live outside this directory and are usable without adopting the study claims here.

The research layer asks how coding-agent harnesses mediate execution routes through tightly specified software work. It does not rank harness products or treat small repeated-run cells as stable pass-rate estimates.

- [`STUDY_OBJECTIVE.md`](STUDY_OBJECTIVE.md) defines the formal study objective and scope.
- [`METHODS.md`](METHODS.md) describes the research design and how focused tasks and scenarios contribute evidence.
- [`scenario-1/FINDINGS.md`](scenario-1/FINDINGS.md) contains the current Scenario 1 interpretation.
- `archive/` contains development-stage notes that are retained for provenance but are not part of the active methodology.
