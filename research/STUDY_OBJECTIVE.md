# Study objective

Agent Harness Smoke is used here to study how coding-agent harnesses mediate software-engineering execution. The primary object of study is the realized interaction route: which workspace primitives a model selects, how those primitives are composed, and how navigation, transformation, recovery, requirement retention, context stewardship, verification, and completion behavior change across harness interfaces and task pressures.

Correctness anchors each trajectory against a common task contract. Harnesses are treated as complete execution interfaces, so observed differences are configuration-level and route-level evidence rather than isolated causal effects of one hidden implementation detail.

## Research questions

1. Primitive realization: when a task permits more than one legitimate workspace interaction primitive, which primitives are actually used by each model-harness configuration?
2. Route composition: how are inspection, localization, editing, structured transformation, testing, and verification composed as task pressure increases from focused operations to multi-surface scenarios?
3. Stewardship and recovery: where do requirement retention, context management, edit-route correction, implementation recovery, verification-probe recovery, and post-green work appear in the trajectory?
4. Affordance uptake: which harness affordances are used, ignored, or substituted with another valid route?

## Scope of claims

The current repeated cells support descriptive route and failure analysis. They do not estimate stable harness success probabilities or establish general reliability, speed, or cost rankings. Larger repeated samples would be needed for population-level performance claims.

## Focused tasks and scenarios

Focused tasks calibrate narrow workspace pressures such as coordinated propagation, selective repeated editing, deletion, extraction, line-oriented filtering, and same-process verification. Scenarios compose several pressures into a coherent maintenance task while retaining one explicit target state and leaving the execution route open.
