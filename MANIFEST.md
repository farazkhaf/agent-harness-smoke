# Release manifest

Agent Harness Smoke v0.2.1 contains:

- six focused Harbor tasks and Scenario 1 under `tasks/`;
- reusable runtime binding, reference OpenCode/Mini-SWE integrations, reporting, and suite utilities under `runtime/`;
- active focused and Scenario 1 suites under `suites/`;
- recorded results under `results/`;
- published run evidence and original/current Scenario 1 evaluator provenance under `evidence/`;
- evaluation, reproducibility, software-attribution, and essential provenance documentation under `docs/`;
- study objective, methods, task-design source index, and findings under `research/`.

The custom harness is represented publicly through recorded outcomes, verifier records, and normalized run telemetry. Its implementation and raw trajectory remain private.

Version 0.2.1 is the canonical release. Release-to-release changes are documented in `CHANGELOG.md`.
